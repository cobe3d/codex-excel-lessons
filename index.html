用 Codex 做 Excel

這學期我們不一個一個儲存格手動輸入，而是把需求「講清楚」給 Codex，讓它寫程式幫我們產生 Excel 檔。你的工作是當專案經理：描述需求、檢查成果、提出修改。

運作方式

Codex 怎麼做出 Excel 檔？

Codex 不會「打開 Excel 點來點去」。它會寫一段 Python 程式（通常用 openpyxl 套件），程式執行後產生 .xlsx 檔。所以每次的流程都是這三步：

步驟 1

用文字描述需求

要有哪些工作表、欄位、公式、格式、圖表，越具體越好。

步驟 2

Codex 寫程式並執行

它會產生 .xlsx 檔。看不懂程式沒關係，但可以請它解釋。

步驟 3

開檔驗收、再修改

改幾個數字測試公式，有問題就再下一句指令修正。

提示詞

好的提示詞長什麼樣子？

同樣是做成績單，講法不同，結果差很多。

太模糊
幫我做一個成績單。

Codex 只能用猜的：幾個學生？哪些科目？要不要排名？做出來的東西通常不是你要的。

夠具體
建立 30 位學生的國文、英文、數學成績，加上總分、平均（小數一位）、排名，平均不到 60 分的整列標淺紅色。所有計算都用 Excel 公式。

人數、欄位、計算方式、格式都講清楚了，第一次就很接近目標。

  • 說清楚結構：工作表名稱、欄位名稱、大概幾筆資料。
  • 指定「用公式」：加一句「所有計算都用 Excel 公式，不要直接填數字」。
  • 講格式：表頭顏色、凍結窗格、條件式格式、數字格式。
  • 一次改一件事：第一版不完美很正常，接著說「把表頭改成藍色」就好。
  • 請它解釋：「說明你用了哪些公式，各是什麼意思」。
  • 給範例資料：要求它先放幾筆假資料，比較好檢查。

常見問題

看到的狀況可能原因可以這樣跟 Codex 說
改了數字，結果沒變結果被直接寫成數字，不是公式「請把所有計算改成 Excel 公式，讓資料修改後會自動更新」
#NAME?用了你的 Excel 版本沒有的函數（例如 XLOOKUP），或函數名稱打錯「我的 Excel 出現 #NAME?，請改用 INDEX 和 MATCH」
######欄寬不夠，數字或日期擠不下「把日期欄的欄寬加大」，或自己拖寬欄位
日期變成 46351 這種數字沒有設定日期格式「日期欄請設定成 yyyy/mm/dd 格式」
下拉選單沒出現沒有設定資料驗證「B 欄請用資料驗證做下拉選單，選項是…」
圖表標題和圖疊在一起圖表設定的小問題「圖表的標題和圖例不要蓋住圖」
期末挑戰

做一個你自己真的會用的 Excel

自己選主題，寫出完整的提示詞，和 Codex 來回修改到滿意為止。發表時要展示：最初的提示詞、修改了幾次、最後的成品，以及你覺得最有用的一個公式。

  • 社團經費或活動報名表
  • 班級座位表或值日生輪值表
  • 畢業旅行預算試算
  • 讀書計畫與考試倒數
提示詞可以自由修改。Codex 每次產生的結果不會完全一樣，和範例檔不同是正常的，重點是功能有沒有做到。
